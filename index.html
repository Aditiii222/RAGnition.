Four RAG Research Frameworks

Retrieval-Augmented Generation spans multiple retrieval paradigms and architectures. This prototype implements functional algorithmic baselines for DPR and CRAG, while distinguishing them from future hierarchical and multimodal research extensions.

Baseline Implemented

Dense Passage Retrieval

DPR (Karpukhin et al., 2020)

Purpose: Retrieve relevant passages from a large text corpus to provide grounded factual context for open-domain question answering.

Status in Prototype: Simplified lexical retrieval baseline implemented (TF-IDF & BM25-inspired term overlap). Full dual-encoder neural DPR utilizing dense BERT embeddings is future work.
Feature Implemented

Corrective RAG

CRAG (Yan et al., 2024)

Purpose: Evaluate retrieval confidence to identify poor, partial, or ambiguous evidence, triggering corrective query reformulation or external search before answering.

Status in Prototype: Basic corrective retrieval implemented: detects weak evidence scores, deterministically expands/broadens query terms, executes a secondary retrieval pass, and compares results.
Future Extension

Hierarchical Summaries

RAPTOR (Sarthi et al., 2024)

Purpose: Cluster text chunks recursively and generate multi-layered summary trees, enabling retrieval across different levels of abstraction (macro themes down to micro details).

Status in Prototype: Future extension; not implemented in this local prototype. The current system operates on a single-tier paragraph chunking index.
Future Extension

Visual Document Retrieval

ColPali (Févry et al., 2024)

Purpose: Index and retrieve visually rich documents (PDFs, tables, diagrams) end-to-end via Vision Language Models (VLMs) and multi-vector late interaction, bypassing imperfect OCR.

Status in Prototype: Future extension; not implemented in this local prototype. The current system operates strictly on plain text representations.

System Architecture

The diagram below illustrates the end-to-end information flow of RAGnition. From query ingestion through chunk indexing, BM25 scoring, confidence assessment, corrective retrieval, and citation-grounded synthesis.

Pipeline Stage Specifications

1. Query Ingestion & Processing

Applies case folding, non-alphanumeric tokenization, stop-word filtering, and term frequency normalization.

2. Lexical Evidence Scoring

Computes inverse document frequency (IDF) across chunks with BM25 term weighting to prioritize distinctive informative words.

3. CRAG Evaluator & Correction

Checks retrieval score confidence. Low scores trigger deterministic query broadening and a comparative secondary pass.

4. Synthesis & Grounding

Extracts top-ranking informative sentences from retrieved chunks, constructing an answer accompanied by interactive citation anchors.

Key Academic Talking Points

  • RAG Motivation: Large Language Models suffer from hallucinations and static knowledge cutoff dates. RAG bridges this gap by grounding generations in an external verifiable document index.
  • Lexical Baseline vs Neural DPR: Our prototype implements a deterministic TF-IDF/BM25 baseline. In production, neural DPR replaces this with dual BERT bi-encoders that map queries and passages to 768-dimensional dense vector spaces, enabling semantic retrieval even with zero vocabulary overlap.
  • The Role of CRAG: Standard naive RAG blindly feeds whatever passages the retriever returns to the generator. CRAG adds an evaluator module: if the retrieved evidence is weak, it triggers corrective actions or abstains, ensuring high factual precision.
